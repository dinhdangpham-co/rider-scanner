🔗 Nạp dữ liệu từ Google Sheets

Publish sheet cần thiết ra TSV:
File → Share → Publish to web → chọn Tab (VD: Rawbatch) → TSV → Publish → copy link.

Hướng dẫn publish Google Sheets:
  1. Mở Google Sheets
  2. File → Share → Publish to web
  3. Chọn tab cần publish (VD: Rawbatch hoặc User)
  4. Chọn format: Tab-separated values (.tsv)
  5. Bấm Publish
  6. Copy link → dán vào ô tương ứng bên trên

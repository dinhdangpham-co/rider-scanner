📖 Hướng dẫn cài Apps Script

  1. Mở Google Sheets → Extensions → Apps Script
  2. Xóa code cũ → paste file Code.gs (đã cung cấp)
  3. Sửa SHEET_ID và API_KEY trong code
  4. Deploy → New deployment → Type: Web app
  5. Execute as: Me | Access: Anyone
  6. Copy URL → dán vào ô "URL Apps Script" bên trên
  7. Bấm Lưu → Sync ngay
